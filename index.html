Each toggle reads the watch's current 0x13 block, flips one bit, and writes it back — all other settings preserved.

Interval Timers · 5 Slots

cycles (1–20)

Names: up to 14 chars, A–Z 0–9 and / + - _ ! ? &. Each slot is mm:ss (minutes 0–60, seconds 0–59). Empty = skipped.

Signal · Push Notification

Pushes a notification to the watch over characteristic 0x30 (bytes transmitted inverted, per the Casio protocol).

Console

What this is: the GBD‑200's own LCD is fixed in ROM and can't be reskinned. This is a companion console that reads and writes the watch's real settings over Web Bluetooth (Chrome / Edge). World-time and fitness-profile writes are documented but held for a future release pending hardware verification. Not affiliated with or endorsed by Casio. Protocol derived from the open-source Gadgetbridge project.
